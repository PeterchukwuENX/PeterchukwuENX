## 👨‍💻 About Me

I'm an **entry-level SOC Analyst** focused on developing practical skills in **security monitoring, threat detection, endpoint investigation, Linux security, and network analysis**.

My approach to cybersecurity is evidence-driven: I focus on understanding **what happened, how it happened, what evidence supports the finding, and what an analyst should do next**.

Through hands-on labs and documented investigations, I've worked with **Windows Event Logs, Sysmon, Linux authentication logs, Wireshark, network segmentation, security hardening, and Python-based security tooling**.

I'm currently strengthening my SOC capabilities while pursuing **CompTIA Security+** and completing cybersecurity training through **TS Academy**, with a long-term interest in **Cloud Security and Identity & Access Management (IAM)**.
